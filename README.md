## Работа с проектом
Инициализация:
```matlab
init
```
Добавляет пути к скриптам и структуру `paramRLSmini` с константами из модели.

Скрипт `fpga_mat2txt_batch` преобразовывает данные из найденных в папке `foldername` .mat файлов в .txt формат по формуле (скрипт `fpga_double2fxp`):
```
fxp = round(flp / 0.0136 * 2^10)
```
Преобразование взято из следующих соображений: 0.0136 - максимальный наблюдаемый уровень в модели, 2^10 - масштабирующий коэффициент.

**Данные от SDR U220 являются 12-битными, при заведении Tx в Rx с tx gain = 70 дБ и rx gain = 0 дБ размах сигнала составляет не менее 3000 в отсчетах АЦП (100 мВ размах на осциллографе). Возможно, скрипты `fpga_double2fxp` и `fpga_fxp2double` нуждаются в корректировке для соответствия данным с платы.**

Запуск:
```matlab
fpga_mat2txt_batch(foldername)
```
Преобразование происходит по нахождению в названии файла одного из следующих ключевых слов:
- tp1_fd
- tp1-fd
- tp2-fap
- tp2_fap
- tp3-lou
- tp3_lou
- tp4-sf-far
- tp4_sf_far
- tp4-sf-near
- tp4_sf_near
- tp5-kn-far
- tp5_kn_far
- tp5-kn-near
- tp5_kn_near

.txt файлы кладутся по тому же пути, что и обнаруженные .mat файлы.

Для передачи .txt файла на плату вызовите команду в консоли, заменив `<path/to/file/and/filename>` на путь к файлу:
```bash
scp <path/to/file/and/filename> mini:~/drivers/ip_comm_test/build
```
Скрипт `check_adc` запускает тест по параметрам в строках 1-12 и анализирует данные с платы с модельными. Внутри запускаются скрипт `launch_ip_comm_test`, который принимает на вход номер тестовой точки, номер канала, количество посылок (посылка - 4 пачки по 232) для передачи(опционально), название текстового файла для передачи в плату(опционально) и базовое название выходного файла (опционально). 

Данные с платы копируются на компьютер скриптом `get_board_data`, первый аргумент скрипта задает папку, в которую данные будут скопированы.

Строки скрипта `check_adc` 41-79 формируют сигнал для проверки практически аналогично модели. **На данный момент есть несовпадение 1 канала для тестовых точек ФАП и ЛОУ из модели и из генерации тестовых данных матлабом. Результат выхода платы для данных точек совпадает с результатов генерации тестовых данных матлабом.**

Для проверки соответствия выводятся графики: весь сигнал из модели, весь сигнал из платы, сигнал из модели для выбранного импульса, сигнал из платы для выбранного импульса, сравнение каждого канала из платы с каждым каналов из модели для выбранного импульса с выводом SQNR.

## SQNR

SQNR позволяет посмотреть точность отображения плавающей точки в фиксированную и считается по формуле:
```
err[n] = x_fp[n] - x_fxp[n]
P_signal = mean(x_fp^2)
P_noise = mean(err^2)
SQNR_dB = 10 * log10(P_signal / P_noise)
```
1 бит ~ 6 дБ SQNR. Для 16-битных сигналов при SQNR менее 30 дБ считается, что точность отображения недостаточна.
